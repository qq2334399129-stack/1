# 大雄无限画布 + 豆包账号池（个人集成版）

本目录是根据用户上传的两个源码压缩包制作的**个人本地集成开发版**，保留大雄 Infinite-Canvas 作为前端画布，以豆包账号池作为视频生成执行后端，并在账号池本地 API 中增加 OpenAI 兼容视频接口。

> 当前状态：已完成源码层面的接口改造与静态语法检查；源码已完成桌面入口调整，但仍需在 Windows 实机重新构建并验证首次启动、账号登录和视频回填。不要把源码构建成功误认为端到端功能已验收。

## 组件与端口

| 组件 | 本地地址 | 作用 |
|---|---|---|
| 大雄 Infinite-Canvas | `http://127.0.0.1:3000/` | 画布界面 |
| 豆包账号池本地 API | `http://127.0.0.1:17888/` | 账号调度、生成任务、状态查询 |
| OpenAI 兼容视频桥接 | `http://127.0.0.1:17888/v1/videos/generations` | 画布提交视频任务 |

桥接接口直接集成在账号池本地 API 服务中，不再需要第三个常驻进程。账号池 API 只绑定 `127.0.0.1`，不向局域网或公网监听。

## 已改造的内容

### 豆包账号池
- API 接收层支持 `referenceImages` 多文件字段，最多 9 张。
- JSON 请求支持 `referenceImagePaths` / `referenceImageUrls` 数组，同时保留旧的单图字段。
- 数据库新增 `reference_image_paths`，旧数据库启动时自动补列；旧任务仍从 `reference_image_path` 兼容读取。
- 执行器按顺序把参考图文件列表交给豆包页面上传控件。
- 新增 `GET /v1/models`、`POST /v1/videos/generations`、`GET /v1/videos/generations/{id}` 和本地 MP4 内容读取接口。
- 画布桥接固定使用本机密钥 `local-doubao-key`；账号池原有 `/api/*` 仍使用账号池设置中的 API Key。
- 账号池 API 继续负责账号额度调度、任务执行和结果校验。

### 大雄无限画布
- 自动注入“豆包账号池”视频 API 平台。
- 默认模型为 `seedance_2_0_mini` 和 `seedance_2_0_fast`。
- 对该平台最多传递 9 张图片；其他 API 平台仍保留原来的 4 张限制。
- 该集成版将画布服务绑定到 `127.0.0.1`，适合个人本机使用。

### 桌面启动
- 以豆包账号池 Electron 程序承载整个工作台，但启动后的主窗口直接显示大雄无限画布；账号池管理界面通过顶部菜单「工作台 → 豆包账号池管理」打开。
- 启动时把画布源码复制到 Electron 用户数据目录，保留 `data`、`assets`、`output`、`API` 和 `workflows/custom` 等用户数据。
- 自动检查画布 Python 依赖；优先尝试本地 wheel，缺少兼容包时需要联网安装。
- 自动启动画布并在主窗口显示；启动期间显示准备提示，启动失败时显示明确错误信息。

## 当前功能边界与待实机验证事项

1. **1～9 张参考图**：代码已扩展到多文件传递；是否能在当前豆包网页界面一次性正确显示并被 Seedance 模型识别，必须在 Windows 登录豆包后实测。若网页控件或当前模型限制多图，需按实测调整上传策略。
2. **画幅**：账号池当前只支持 `16:9` 和 `9:16`，其他画幅会返回明确错误。
3. **模型**：当前只映射账号池已有的 Seedance 2.0 Mini / Fast。
4. **时长**：账号池 API 没有独立时长字段。桥接层把画布的时长值追加为提示词中的“视频时长：N秒”指令；它不是对上游时长参数的硬性保证。
5. **视频/音频参考**：当前桥接只支持图片参考，不支持参考视频或参考音频。
6. **去水印**：账号池当前任务流程要求配置去水印服务 Token。请在豆包账号池设置里填写你有权使用的服务 URL 和 Token。未配置 Token 时，桥接会在提交任务前明确报错，避免先消耗账号额度再失败。不要把 Token、Cookie 或账号密码发到聊天或公开仓库。
7. **Windows 实测**：尚未验证豆包登录、页面上传、任务生成、去水印 MP4 回传和异常恢复的完整链路。

## 首次使用准备

- Windows 10/11 x64。
- 网络可访问豆包和 Python 包源（如果随包 wheel 与 Python 3.10 不兼容，需要在线安装依赖）。
- 在账号池中自行登录有权使用的豆包账号。
- 在账号池设置中配置去水印服务 Token。
- 画布 API 设置中会自动出现“豆包账号池”平台；默认本地 API Key 为 `local-doubao-key`，不要把账号池 API 端口暴露到公网。

## 构建 Windows 安装包

推荐使用 GitHub Actions 的 Windows 云构建：将整个目录上传到自己的 GitHub 仓库，在仓库的 **Actions → Build Windows Setup.exe → Run workflow** 中启动构建，完成后从运行记录的 Artifacts 下载安装包。工作流文件位于 `.github/workflows/build-windows.yml`。

也可以在 Windows 开发环境安装 Node.js 20/22 后，双击 `build-windows.bat`。该方式会调用 `build-windows.ps1`，安装依赖并用 Electron Builder 生成 NSIS 安装程序；构建过程需要访问 npm registry。

输出目录：
`doubao-account-pool/release/`
