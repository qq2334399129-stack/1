小野作品集 · 宝塔直接解压版

网页文件直接位于压缩包第一层。选择宝塔「网站」对应站点的「根目录」作为解压位置。
例如站点根目录是 /www/wwwroot/xiaoye，就解压到该目录，覆盖已有网站文件。
解压后该目录直接看到 index.html、xiaoye-api.php、admin 和 assets 即可。

宝塔文件管理
1. 在「网站」找到这一个站点，点它的根目录地址打开文件管理。
2. 上传 xiaoye-baota.zip，在文件列表点 ZIP 的「解压」。目标选当前站点根目录。
   如果面板自动填入了 xiaoye-baota 子目录，删除这一段路径，再点确定。
3. 打开这个站点原有的网址，按 Ctrl+F5 刷新。山景和示例视频可直接显示。

后台首次设置
1. 在该站点设置里选 PHP 8.1 或以上，建议用宝塔已安装的 PHP 8.2/8.3/8.4。
   然后打开该站点网址末尾加 /admin/ 。此 PHP 版不需要 Node、npm 或反向代理。
2. 首次打开会显示「首次设置后台」。这时在宝塔文件管理中显示隐藏文件，
   进入 .xiaoye-data，编辑查看 install-key.php，复制 JSON 的 code 值（引号内的字符串）。
3. 将安装码填进设置页面，设置至少 12 位密码。之后用户名为 admin，用你设置的密码登录。
   初始安装码在完成设置后自动失效。请通过 HTTPS 登录正式站点。

登录后的入口
- 首页介绍：站名、封面、头像、AI 订阅链接、服务介绍。
- 联系方式与链接：QQ 和微信的跳转链接、二维码及邮箱。
- 视频管理：上传 MP4 或 WebM，修改标题、说明和封面。多个视频在手机上可横滑切换。
- SKU 作品、人物与建筑资产：分别维护 /sku/ 和 /assets-library/，支持效果图和提示词。
- AI 工具分享：每个文件可写介绍，默认联系获取，也可设为公开下载。
- 修改后点「保存并发布」。

部署与备份
- 如果后台提示 PHP 未接通，确认你看到的是这个站点的根目录，并在设置中启用 PHP。
  访问 /xiaoye-api.php?action=health，应返回含 xiaoye-portfolio-php 的 JSON。
- 图片上限 16 MB，视频 512 MB，资料文件 256 MB；还受宝塔和 PHP 的上传限制。
  遇到 413，在对应站点配置里提高 client_max_body_size，再按需检查 PHP 大小与超时设置。
- .xiaoye-data 保存后台密码哈希、内容和文件。备份与升级时保留此目录。
  如停用 PHP，请将该目录迁出网页根目录。Nginx 可额外添加下面的站点内规则：
    location ^~ /.xiaoye-data/ { return 404; }
- 已经用旧 Node 版本保存的 data 目录与本版格式不同。保留旧目录作为备份。
